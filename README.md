# Horizon-Assault-First-Person-Shooter-3D
A 3D First-Person Shooter (FPS) game made with Unity and C#. The game features enemy AI, multiple weapons, shooting mechanics, and ammo management.

## Features
* First-person player controller
* NavMeshAgent-based enemy AI
* Weapon pickup, equip, and switching
* Multiple weapons
* Raycast-based shooting
* Shooting cooldown system
* Ammo and ammo pickups
* Gun recoil and camera shake
* Projectile-based attacks
* Enemy detection using Physics.OverlapSphere
* Gun sound effects
* Player and weapon animations
* Enemy and weapon systems

##  Built With
* Unity
* C#
* Unity Animator
* Unity AI Navigation (NavMesh)
* ProBuilder
* ScriptableObjects

## What I Learned
* Creating a first-person controller
* Implementing enemy AI with NavMeshAgent
* Using Raycasting and different Raycast overloads
* Equipping, picking up, and switching weapons
* Managing ammo and shooting cooldowns
* Using ScriptableObjects to store weapon data
* Applying inheritance in C#
* Working with projectiles and physics
* Using Physics.OverlapSphere for enemy detection
* Adding gun recoil, camera shake, and sound effects
* Creating animations and Animator transitions
* Using OnDrawGizmos to visualize detection ranges
* Building 3D environments with ProBuilder

##  About This Project
I built this project to practice Unity and C# by creating a 3D FPS game. It helped me understand weapon systems, enemy AI, raycasting, object-oriented programming, and Unity's physics and animation systems.
